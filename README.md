# Savage Auth Project

This full-stack web application lets users create an account, log in, and participate on a shared message board. Once signed in, users can post messages, react with thumbs up or thumbs down, and manage their profiles through login and logout functionality.

## Tech Used:
- HTML
- CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js

## Lessons Learned:
- Connected the backend to a MongoDB database using Mongoose
- Understanding more of middleware functions and how data moves between the frontend, backend, and database.
- Discovered how to use MongoDB’s $inc operator to modify numeric values

## Installation

1. Clone repo
2. run `npm install`

## Usage

1. run `node server.js`
2. Navigate to `localhost:8080`
